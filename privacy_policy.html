Kebijakan Privasi Skanida Teacher

Berlaku sejak: 16 Oktober 2026
Pengelola: SMK Negeri 2 Semarang
ID aplikasi: com.sahasika.skanida_teacher

Kebijakan Privasi ini menjelaskan bagaimana aplikasi Skanida Teacher ("Aplikasi") yang dikelola oleh SMK Negeri 2 Semarang ("Sekolah", "kami") mengumpulkan, menggunakan, menyimpan, dan melindungi data pribadi pengguna. Dengan menggunakan Aplikasi, Anda menyetujui pemrosesan data sebagaimana dijelaskan di bawah ini.

1. Ruang Lingkup

Aplikasi ini ditujukan khusus bagi guru dan tenaga pendidik SMK Negeri 2 Semarang untuk mengelola jurnal mengajar, presensi siswa, jurnal kelas, dan persetujuan ijin keluar kelas siswa. Akun pengguna dibuat dan dikelola oleh Sekolah; Aplikasi tidak menyediakan pendaftaran akun mandiri. Aplikasi terhubung ke sistem informasi Sekolah di apps.smkn2semarang.sch.id.

2. Data yang Kami Kumpulkan dan Proses

KategoriJenis dataSumber
Data akun Username dan kata sandi (hanya dikirim saat login, tidak disimpan di perangkat), token sesi Diisi oleh pengguna
Profil guru Nama, NIP, NIK, email, nomor HP, tempat dan tanggal lahir, alamat (termasuk RT/RW, kelurahan, kecamatan, kota, provinsi), data kepegawaian (TMT CPNS/PNS, pangkat, golongan), mata pelajaran, dan foto profil Sistem informasi Sekolah, ditampilkan di Aplikasi
Data siswa Nama siswa, NIS, NISN, kelas, status dan waktu kehadiran, serta data ijin keluar kelas (jenis ijin, tanggal, jam pelajaran, keperluan, status validasi BK/guru) Sistem informasi Sekolah, diakses oleh guru
Aktivitas pembelajaran Jurnal mengajar (kelas, mata pelajaran, tanggal, jam pelajaran, materi, catatan), perubahan status presensi siswa, dan persetujuan ijin siswa Diisi oleh pengguna
Data di perangkat Status login, token sesi, nama pengguna, dan ID guru Disimpan lokal di perangkat

Aplikasi tidak mengumpulkan data lokasi, kontak, foto/berkas di perangkat, rekaman suara, riwayat penelusuran, maupun ID iklan.

3. Tujuan Penggunaan Data

  • Memverifikasi identitas guru saat login dan menjaga sesi tetap aktif.
  • Menampilkan profil guru.
  • Mencatat dan menampilkan jurnal mengajar serta jurnal kelas.
  • Mencatat dan memperbarui presensi siswa.
  • Meninjau dan menyetujui permohonan ijin keluar kelas siswa.
  • Mendukung administrasi akademik Sekolah.

Data tidak digunakan untuk iklan, pemasaran, atau pembuatan profil komersial.

4. Izin Perangkat

Aplikasi hanya meminta izin Akses Internet untuk berkomunikasi dengan server Sekolah. Aplikasi tidak meminta izin kamera, mikrofon, lokasi, kontak, maupun penyimpanan.

5. Penyimpanan dan Keamanan Data

  • Seluruh komunikasi antara Aplikasi dan server Sekolah dienkripsi menggunakan HTTPS.
  • Data utama disimpan di server sistem informasi milik SMK Negeri 2 Semarang, bukan di perangkat.
  • Akses ke data memerlukan token autentikasi yang diberikan setelah login berhasil.
  • Data yang disimpan di perangkat (status login, token, nama pengguna, ID guru) dihapus saat pengguna memilih Logout atau menghapus Aplikasi.
  • Kata sandi tidak disimpan di perangkat.

Kami berupaya melindungi data dengan langkah yang wajar, namun tidak ada metode transmisi atau penyimpanan elektronik yang sepenuhnya aman.

6. Berbagi Data

Kami tidak menjual, menyewakan, atau membagikan data pribadi kepada pihak ketiga. Data hanya dapat diakses oleh pihak berwenang di lingkungan SMK Negeri 2 Semarang sesuai tugasnya, atau diungkapkan apabila diwajibkan oleh peraturan perundang-undangan atau permintaan resmi instansi berwenang.

7. Layanan Pihak Ketiga

Aplikasi tidak menggunakan layanan analitik, iklan, atau pelacakan pihak ketiga.

8. Data Siswa

Siswa bukan pengguna Aplikasi. Data siswa diproses oleh guru semata-mata untuk keperluan pendidikan dan administrasi Sekolah, berdasarkan kewenangan SMK Negeri 2 Semarang sebagai satuan pendidikan. Aplikasi menampilkan data siswa hanya kepada guru yang telah login.

9. Retensi Data

Data di server disimpan selama diperlukan untuk keperluan administrasi akademik dan sesuai ketentuan pengarsipan Sekolah. Data di perangkat disimpan sampai pengguna logout atau menghapus Aplikasi.

10. Hak Pengguna dan Penghapusan Data

Sesuai Undang-Undang Nomor 27 Tahun 2022 tentang Pelindungan Data Pribadi, Anda berhak untuk:

  • mengakses dan memperoleh informasi tentang data pribadi Anda;
  • meminta perbaikan data yang tidak akurat;
  • meminta penghapusan akun dan data pribadi Anda.

Permintaan penghapusan akun atau data dapat diajukan melalui email ke [EMAIL_RESMI_SEKOLAH] dengan subjek "Penghapusan Akun Skanida Teacher", disertai nama dan NIP Anda. Permintaan akan diproses paling lambat 30 hari. Data tertentu dapat tetap disimpan apabila diwajibkan oleh ketentuan pengarsipan atau peraturan yang berlaku. Data di perangkat dapat dihapus sendiri dengan melakukan Logout atau menghapus Aplikasi.

11. Perubahan Kebijakan

Kebijakan Privasi ini dapat diperbarui sewaktu-waktu. Perubahan akan dipublikasikan di halaman ini dengan memperbarui tanggal berlaku di bagian atas.
